# OmnesBnb

Projet de groupe orienté développement web, combinant **PHP**, **JavaScript** et **CSS**, réalisé dans un cadre académique.

> 🎓 Réalisé dans le cadre d’un projet scolaire avec l’**ECE Lyon**.  
> 📜 Les droits associés au projet appartiennent à l’**ECE Lyon**.

---

## 🚀 À propos du projet

**OmnesBnb** est une application web inspirée des plateformes de réservation/location, développée en équipe.  
Le projet met en œuvre un back-end en PHP, une interface dynamique en JavaScript et une couche de présentation en CSS.

Ce dépôt reflète un travail collaboratif complet autour de :

- la conception d’une application web structurée,
- l’intégration front/back,
- la gestion de données côté serveur,
- la qualité UX/UI et la maintenabilité du code.

## 🚀 Installation & lancement

### 1) Cloner le dépôt

```bash
git clone https://github.com/JeremyGnt/OmnesBnb.git
cd OmnesBnb
```

### 2) Configurer l’environnement

- Vérifier/adapter les paramètres dans les fichiers de configuration (`config/`).
- Si base de données :
  - créer la base,
  - importer le script SQL (si fourni),
  - renseigner les identifiants de connexion.

### 3) Démarrer l’application

Selon ton environnement :

- via Apache/Nginx (dossier servi par le virtual host),
- ou avec le serveur PHP natif :

```bash
php -S localhost:8000 -t public
```

Puis ouvrir :  
`http://localhost:8000`
